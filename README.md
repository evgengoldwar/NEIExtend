# NEIExtend

Клиентский аддон для [NotEnoughItems (GTNH)](https://github.com/GTNewHorizons/NotEnoughItems), Minecraft 1.7.10.
Позволяет прямо в игре, через удобное окно, скрывать ненужные **вкладки** (обработчики рецептов) и отдельные
**рецепты** внутри вкладок.

*Client-side NEI addon: hide the recipe tabs and single recipes you don't need, from a screen in the game.*

## Как пользоваться

Откройте рецепты (R) или применения (U) любого предмета. Справа от окна NEI появится маленькая панель из четырёх кнопок:

| Кнопка | Что делает |
| --- | --- |
| Перечёркнутый глаз | Скрывает показанную вкладку — сразу для всех предметов |
| Звезда | Делает показанную вкладку первой (у всех предметов). Повторное нажатие — вернуть обычный порядок |
| Прицел | Режим скрытия рецептов: наведите на рецепт (он подсветится красным) и щёлкните — рецепт пропадёт. ПКМ — выйти |
| Шестерёнка | Окно NEIExtend со списками всего скрытого |

После каждого скрытия под окном NEI на несколько секунд появляется плашка с кнопкой **«Отменить»**.

### Окно NEIExtend

- **Вкладки** — все вкладки NEI, сгруппированные по модам. У заголовка мода: стрелка сворачивания (Shift — все моды),
  счётчики, звезда «закрепить все вкладки мода» и переключатель «скрыть/показать все вкладки мода».
  У каждой вкладки: регулятор места `▲ #3 ▼` (▲ — закрепить/выше, ▼ — ниже/убрать, Shift — в начало/убрать сразу,
  щелчок по номеру — ввести место с клавиатуры, колесо мыши — двигать), метки `R`/`U` и переключатель видимости.
  Поиск (по названию, моду, id) и фильтр «Все / Видимые / Скрытые». **ПКМ** открывает вкладку со всеми рецептами.
- **Порядок** — закреплённые вкладки, которые показываются первыми, сверху вниз. Строки можно перетаскивать
  мышью или двигать стрелками (Shift — в начало/в конец), крестик убирает вкладку из списка.
  Остальные вкладки идут после, в порядке NEI. На странице «Вкладки» звезда у вкладки добавляет её в конец этого списка.
- **Рецепты** — все скрытые рецепты: результат, вкладка, ингредиенты и кнопка «Вернуть».
  ПКМ по строке открывает вкладку этого рецепта со всеми рецептами.
- **Справка** — коротко о том же.

Окно также открывается клавишей из настроек управления (по умолчанию не назначена).
При закрытии окна открытое окно рецептов NEI обновляется: возвращённые вкладки и рецепты сразу появляются.

## Технически

- Только клиент: на сервер ставить не нужно, работает на любом сервере (`acceptableRemoteVersions = "*"`).
- Всё хранится в `config/neiextend.json`. Вкладки — по `handlerId` (тот же id, что в `hiddenhandlers.cfg` NEI),
  рецепты — по `RecipeId` NEI (обработчик, ингредиенты, результат).
- Скрытые рецепты отсекаются через `IRecipeFilter` NEI (как пресеты NEI), скрытые вкладки — late-миксином
  в `RecipeHandlerQuery`. Отрисовка, тултипы и место под панель — через хуки NEI
  (`IContainerDrawHandler`, `IContainerTooltipHandler`, `INEIGuiHandler`), клики — миксином в `GuiRecipe`.
- Порядок вкладок: компаратор сортировки NEI подменяется (`@ModifyArg` в `RecipeHandlerQuery` и
  `GuiRecipe.forceRefreshPage`) — закреплённые вкладки идут первыми, остальные сохраняют порядок `handlerordering.csv`.
- Требуется GTNH NEI 2.8.x.
